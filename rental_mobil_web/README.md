# Website Rental Mobil (Flask + MySQL Laragon)

1. Laragon: Start All. Di phpMyAdmin tab SQL (halaman utama), jalankan rental_mobil_lengkap.sql
2. Terminal di folder ini:
   pip install -r requirements.txt
   python app.py
3. Client : http://localhost:5000/
   Admin  : http://localhost:5000/admin/login  (Rahulhukama / password123)
